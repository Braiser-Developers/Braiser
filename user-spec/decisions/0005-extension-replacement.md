# D-0005 修复旧扩展连接取消新连接请求的问题

- 状态：有效
- 日期：2026-11-12
- 决策者：agent
- 服务于：[作者预期](../overview.md)、[D-0002](0002-remote-access.md)

## 背景

扩展重连时旧 socket 的异步 close 可能晚于新连接建立。

## 决策

替换连接前终止旧请求；close/message 回调只处理当前扩展 socket，旧连接不能影响新请求。

## 修复的 bug

- 现象：扩展重连时，新请求可能被旧连接 close 事件误报失败。
- 原因：pending 全局共享，而 close 回调没有确认连接身份。
- 为什么原来的做法会出 bug：过期连接可能异步关闭，不能让它清理当前连接请求。
- 怎么验证修好了：extension replacement 测试验证旧请求失败、新快照成功。
