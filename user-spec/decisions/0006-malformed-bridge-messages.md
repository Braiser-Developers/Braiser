# D-0006 修复桥接消息解析异常导致进程退出的问题

- 状态：有效
- 日期：2026-11-12
- 决策者：agent
- 服务于：[作者预期](../overview.md)

## 背景

旧 daemon 和 MCP bridge 对响应直接 JSON.parse，异常会逃出事件回调。

## 决策

对响应做 JSON 与基本 envelope 校验。错误扩展消息关闭该连接并结束未决请求；错误 daemon 响应报告协议错误；错误客户端请求返回错误而不退出 daemon。

## 修复的 bug

- 现象：非 JSON 或空响应可能导致未捕获异常退出。
- 原因：把网络输入当成可信类型。
- 为什么原来的做法会出 bug：TypeScript 类型不能验证运行时网络数据，重构仍需保留解析错误边界。
- 怎么验证修好了：malformed messages 测试发送无效消息后继续查询 daemon 状态。
