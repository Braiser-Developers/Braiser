# D-0017 不丢可见信息的快照压缩

- 状态：有效
- 日期：2026-11-13
- 决策者：agent
- 服务于：
  - 作者预期：[overview.md「observe 改版」](../overview.md)（页面快照的文字、结构都要保留）、[overview.md「设计初衷」](../overview.md)（更少的 token）
  - 上游决策：[D-0016](0016-observe-output-format.md)

## 背景

作者请 agent 逐项查看维基和 GitHub 快照中正文和链接的具体内容，找保留信息又省 token 的办法。2026-11-13 的分析（见 [token 实测](../../references/browser-snapshot-tokens-2026-11-13.md)）发现：

- 英文维基快照里 31% 的 token 是参考文献里的 COinS 元数据（`<span class="Z3988" title="ctx_ver=...">`）。它是没有尺寸的空元素，只在 title 里重复了旁边可见的引用信息，Playwright 因为它对无障碍树可见而保留了它。
- GitHub 仓库页的网址几乎都以仓库路径 `/microsoft/playwright-mcp` 开头；同一个提交链接在一行里出现三次（提交说明、PR 号、右括号各是一个链接），每次都带 40 位哈希。
- 表格每行要拆成 row、cell 多行，再加 rowgroup 外层；列表里每个只包一个链接的 listitem 也占两行。

## 决策

在 D-0016 的格式上增加五种压缩，都不删除页面上人能看到的内容：

1. **不可见元数据**：没有尺寸、没有内容、只靠 title 之类得到名称的 generic 节点不输出。
2. **页面路径简写**：主 frame 中，以本页路径开头的同站网址写成 `~/...`，快照开头写一行 `- url alias: ~ = /路径`。
3. **重复网址引用**：16 个字符以上的网址第二次出现时写成 `=E12`（与 E12 相同）；一个网址以前面出现过的网址结尾时（如 `web.archive.org/web/<时间>/<原网址>`），结尾部分写成 `=E12`。
4. **表格行**：单元格都是简短行内内容的行写成一行 `- row: a | b | c`，表头行标 `[header]`，单元格里的 `|` 转义为 `\|`；rowgroup 外层不再单独占一行。
5. **单子元素包装**：只包着一个可行内显示的子元素的节点（如只含一个链接的 listitem）写成一行，例如 `- listitem: [Pricing](E7 /pricing)`。

`browser.observe` 的工具说明里写明 `~` 和 `=E12` 的含义。`RenderOptions.disable` 可以逐项关闭这些压缩，用于测量和测试。

## 考虑过、没有采用

- 截短 GitHub 提交哈希：GitHub 接受短哈希，但字符串变了，属于有损，而且只适用于 GitHub。
- 去掉维基参考文献里的"Jump up"回链和本页锚点：页面上看得见，也能点，属于有损。
- 根据链接文字推出维基内链网址（`/wiki/Lightweight_markup_language`）：只省约 2%，规则依赖站点且大小写不可逆。

## 代价

- Agent 需要理解 `~` 和 `=E12` 两种简写，网址不再每处都自成一体。
- 只靠 title 提供信息、自身没有尺寸的元素会被省略；目前只针对 generic 角色。

## 什么时候应该重新考虑

Agent 经常误解简写，或者发现被省略的不可见元素里有页面上看不到却有用的信息时。
