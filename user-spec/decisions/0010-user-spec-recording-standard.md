## 背景

作者更新了 user-spec 技能并要求同步。新版要求忠实于作者的含义，由 agent 主动合并主题、展开对话指代，写成脱离会话也能读懂的文档。原有总览逐条摘录了需求、一次性工作指令和历史材料处理答复，需要按新版规则整理。

## 决策

逐段比较六份规则模板，更新 AGENTS.md、user-spec/README.md 和 user-spec/vision.md 的记录规则。其余三份模板规则正文相同，保留已有索引；决策索引增加本条并标注 D-0008 的部分替代关系。

总览只按项目定位与当前远程访问需求叙述，保留轻量级目标、远程 Linux Agent 操作本机浏览器，以及当前先支持浏览、点击、填写和读取内容的阶段范围。SSH 方案和启动入口作为做法链接到已有决策，不另标“agent 注”。

采用 user spec 的工作指令、旧材料保留为历史的确认，已经记录在 D-0008 和材料归位文档中，不在总览重复。旧定位、原始笔记和设计草稿保持原样，愿景不增加作者未确认的内容。
